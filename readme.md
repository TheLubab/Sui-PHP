# Sui Wordpress Plugins

## Description 
Wordpress plugins for integrating the Sui blockchain. 

Bring the power of web3 to traditional web2 websites through a suite of WordPress plugins and a PHP SDK. These tools enable seamless integration of trustless authentication, secure payments, and permissionless monetization strategies. Designed for ease of use, speed, and transparency, our solution allows web2 sites to harness the benefits of blockchain technology effortlessly.

## Installation 

1. Download the plugin zip from release page.
2. Upload the zip to the `/wp-content/plugins/` directory unzip it, or just install the plugin through the WordPress
   plugins screen directly.
3. Activate the plugin through the 'Plugins' screen in WordPress


# Sui PHP SDK

Still not published to composer, but you can directly using it by cloning or copying the repo code.

**features**

1. Verify Personal Message Signature
2. Convert Public Key to SUI Address
3. Parse Serialized Signature
4. Validate SUI Address

For detailed usage and examples, see the [full README](php-sui-sdk/readme.md).
